# 敲击背板功能拓展指南

本文档说明如何为敲击背板功能添加新的动作（触发行为）。

---

## 架构概览

```
TapDetector (传感器监听 + TFLite 推理)
    ↓ 检测到敲击
OverlayService.handleTapAction(tapCount)
    ↓ 根据 Prefs 查找动作 ID
TapActionRegistry.findById(actionId)
    ↓ 执行动作
TapAction.execute(context)
```

---

## 添加新动作的步骤

### 第 1 步：创建动作类

在 `app/src/main/java/com/taostudio/tapaccounting/tap/` 目录下创建新文件：

```kotlin
package tao.test.tapaccounting.tap

import android.content.Context

class YourNewAction : TapAction {
    override val id = "your_action_id"          // 唯一标识符，存入 Prefs
    override val displayName = "你的动作名称"    // 在选择器中显示的名称

    override fun execute(context: Context) {
        // 在这里实现你的动作逻辑
        // context 是 OverlayService 的 Context
        // 可以启动 Activity、发送广播、调用系统 API 等
    }
}
```

### 第 2 步：注册动作

在 `TapAction.kt` 的 `TapActionRegistry.init` 块中添加一行：

```kotlin
init {
    register(ShowOverlayAction())
    register(OpenAiChatAction())
    register(YourNewAction())    // ← 添加这一行
}
```

新动作会自动出现在灵敏度设置页的动作选择器中，无需修改 UI 代码。

### 第 3 步：完成

无需其他修改。系统会自动：
- 在选择器中显示新动作
- 保存用户选择到 Prefs
- 检测到敲击时执行对应动作

---

## 动作执行环境

`execute(context)` 运行在 **OverlayService 的主线程**中。注意事项：

| 操作 | 说明 |
|------|------|
| 启动 Activity | 需要 `FLAG_ACTIVITY_NEW_TASK`（因为 context 是 Service） |
| 显示悬浮窗 | 已有 `canDrawOverlays` 权限检查 |
| 耗时操作 | 请用协程或后台线程 |
| 系统权限 | 部分操作可能需要 Shizuku（参考现有 Shizuku 模式） |

## 现有动作参考

### ShowOverlayAction（弹出悬浮窗）

```kotlin
class ShowOverlayAction : TapAction {
    override val id = "show_overlay"
    override val displayName = "弹出悬浮窗"
    override fun execute(context: Context) {
        val intent = Intent(context, OverlayService::class.java).apply {
            action = OverlayService.ACTION_SHOW_OVERLAY
        }
        context.startService(intent)
    }
}
```

### OpenAiChatAction（AI 智能记账助手）

```kotlin
class OpenAiChatAction : TapAction {
    override val id = "open_ai_chat"
    override val displayName = "AI 智能记账助手"
    override fun execute(context: Context) {
        val intent = Intent(context, ChatActivity::class.java).apply {
            putExtra(ChatActivity.EXTRA_SOURCE_BOOK, BookAccountManager.getSelectedBook(context))
            addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
        }
        context.startActivity(intent)
    }
}
```

## 双击 vs 三击

- 双击和三击可以配置不同的动作
- 用户在灵敏度设置页中分别选择
- `tapCount` 参数（2 或 3）决定了执行哪个动作
- 三击模式需要先在设置中开启，否则只检测双击

## 常见拓展场景

### 打开指定页面

```kotlin
override fun execute(context: Context) {
    val intent = Intent(context, YourActivity::class.java)
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
    context.startActivity(intent)
}
```

### 发送广播

```kotlin
override fun execute(context: Context) {
    context.sendBroadcast(Intent("your.action.name"))
}
```

### 调用 Shizuku 命令

```kotlin
override fun execute(context: Context) {
    if (!tao.test.tapaccounting.ShizukuSafe.isReady(context)) return
    tao.test.tapaccounting.ShizukuShell.exec("your shell command")
}
```

### 显示 Toast

```kotlin
override fun execute(context: Context) {
    android.widget.Toast.makeText(context, "敲击检测到！", android.widget.Toast.LENGTH_SHORT).show()
}
```

## 文件清单

| 文件 | 作用 |
|------|------|
| `tap/TapAction.kt` | 动作接口 + 注册表 + 现有动作实现 |
| `tap/TapDetector.kt` | 检测敲击并回调 OverlayService |
| `OverlayService.kt` | 接收回调，查找并执行动作 |
| `ui/SensitivityActivity.kt` | 设置页，动作选择器 UI |
| `PrefsGeneralSupport.kt` | 偏好存储（动作 ID） |
